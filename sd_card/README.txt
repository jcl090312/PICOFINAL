Grove MP3 V4 시연용 경보음

0001.mp3: 주의 경보용 짧은 반복음 (약 2.4초)
0002.mp3: 위험 경보용 두 음 교대음 (약 3초)
0003.mp3: 관리자 스피커 시험용 세 음 (약 1.2초)

이 파일들은 새로 합성한 테스트 톤이며 한국어 말소리가 아닙니다.
FAT16/FAT32로 준비한 32GB 이하 microSD의 최상위 폴더에 MP3 파일 세 개를 넣으세요.
Pico나 Thonny에 넣는 파일이 아닙니다. 폴더째 넣지 말고 MP3 세 개를 직접 넣습니다.
기존 데이터가 있는 카드를 포맷하면 지워지므로 빈 카드 또는 이미 맞는 형식의 카드를 사용하세요.

한국어 안내를 쓰려면 직접 녹음하거나 만든 안내를 실제 MP3 형식으로 내보내고
같은 파일명으로 교체할 수 있습니다. 파일 확장자만 바꾸는 것은 변환이 아닙니다.
예: 주의 - '가스 센서의 주의 상태가 확인되었습니다. 주변을 확인해 주세요.'
    위험 - '가스 센서의 위험 상태가 확인되었습니다. 안전한 장소로 이동해 주세요.'
짧은 파일을 사용하세요. 기본 자동 재생 간격은 15초이고, 한 곡 반복 모드를 사용하지 않습니다.

전송 응답 OK만으로 스피커에서 실제 소리가 났는지는 알 수 없습니다.
먼저 관리자 'MP3 소리 5초' 시험으로 카드, 파일 이름, 스피커와 볼륨을 확인하세요.
기본 볼륨은 8/31입니다. 학교에서는 시험 전에 주변에 알리고 작은 볼륨부터 확인하세요.

파일 생성 코드: tools/make_demo_audio.py (FFmpeg는 재생성할 때만 필요)
